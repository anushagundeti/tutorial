# 🌱 Spring Boot User API

A basic RESTful API built using **Spring Boot**, designed to demonstrate simple user management with GET and POST operations.

This project includes a `UserController`, a `UserService`, and a `User` model — showcasing clean architecture and REST principles.

---

## 📌 Features

- 📦 `GET /api/users` – Retrieve all users
- 📝 `POST /api/users` – Create a new user
- 🧱 Layered structure (Controller → Service → Model)
- ✅ JSON-based request and response
- 🛠️ Spring Boot auto-configuration

---

## 🧱 Tech Stack

- **Framework**: Spring Boot (Java)
- **Build Tool**: Maven or Gradle
- **Language**: Java 17+
- **Data Handling**: Jackson for JSON
- **REST API**: Spring Web (`@RestController`)
